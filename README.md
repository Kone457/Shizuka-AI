# شيزوكا AI 🌟

**بوت واتساب عربي بالكامل** — أوامر مصرية، منيو بالعربي، أزرار حقيقية، وردود باللهجة المصرية.

</div>

---

<div dir="rtl">

## ✨ المميزات

| | |
|---|---|
| 🗂️ **١٠ أقسام** | منيو مرقّم — `.منيو` وبعدها `.ق1` … `.ق10` |
| 🇪🇬 **أسماء مصرية** | `.منيو` · `.الاوامر` · `.المطور` · `.ضيف` · `.تبنيد` · `.المبندين` · `.جروب` · `.تاج` · `.اكس` · `.رهان` |
| 🧩 **١٥٨ plugin** | مشرفين · ألعاب · اقتصاد · تحميل · بحث · أنمي · ذكاء اصطناعي · أدوات · مطور · بوتات فرعية |
| 🎛️ **أزرار حقيقية** | ردود بأزرار تفاعلية مش نص بس |
| 🔎 **تحميل تفاعلي** | `.يوتيوب` بيعرض ٥ نتايج بأرقام — تختار ١ صوت أو ٢ فيديو |
| 💬 **ردود مصرية** | كل الرسايل بالعامية المصرية |
| 🛡️ **حماية الجروب** | منع اللينكات · منع القنوات · الترحيب والمغادرة · الانذارات · كتم · طرد |
| 🧪 **٤٢ اختبار** | `npm test` بيجرّب كل أمر ويتأكد إنه مش بيكسر |

</div>

## 🚀 التشغيل

```bash
git clone https://github.com/Kone457/Shizuka-AI
cd Shizuka-AI
npm install
npm start
```

بعد كده اختار:

```
✿ 1. بكود QR
✿ 2. بكود نصي من 8 أرقام
```

> محتاج **Node.js 18+**.

## 📱 الأوامر الأساسية

```
.منيو            → قايمة الـ١٠ أقسام
.ق1              → أوامر المشرفين
.ق5              → أوامر الألعاب
.المطور          → بيانات المطور
.ضيف 2010…       → ضيف عضو للجروب
.المبندين        → قايمة المحظورين
.يوتيوب بحلم       → تحميل من يوتيوب
.بينج            → سرعة البوت
```

كل الأقسام:

```
1️⃣ المشرفين        6️⃣ أنمي
2️⃣ ذكاء اصطناعي    7️⃣ الاقتصاد
3️⃣ البحث           8️⃣ أدوات
4️⃣ التحميل         9️⃣ المطور
5️⃣ ألعاب           🔟 بوتات فرعية
```
